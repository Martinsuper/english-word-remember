# 英语阅读模块产品需求文档（PRD）

> 文档状态：Draft v1.0
> 适用产品：考研英语闪卡
> 目标版本：Reading MVP
> 更新日期：2026-07-12

## 1. 文档目的

本文定义英语阅读模块的产品目标、范围、用户流程、功能需求、验收标准和发布门禁。技术实现详见 `docs/02-design/english-reading-module-technical-design.md`。

## 2. 背景与机会

当前产品已经支持词库、学习计划、单词卡、收藏、错词和 SM-2 间隔复习，但单词主要来自预置或导入词表，缺少真实上下文。

英语阅读模块需要建立以下闭环：

```text
导入/获取 EPUB → 阅读文章 → 点击生词 → 查看释义和发音
             → 加入阅读生词 → 进入学习计划 → 间隔复习
             → 从单词卡返回原文语境
```

外部内容项目 `hehonghui/awesome-english-ebooks` 收录《经济学人》《纽约客》《The Atlantic》《Wired》等刊物，主要提供 EPUB、MOBI 和 PDF 文件并持续更新。它可用于研究目录结构和开发期样例，但仓库未声明许可证，刊物内容也可能受第三方版权保护。

## 3. 产品原则

1. 阅读服务于学习：核心价值是把真实语境转化为可复习知识，而不是复刻通用阅读器。
2. 离线优先：已经导入或下载的书籍应在无网络时完整可读。
3. 用户掌控内容：用户能查看占用空间并删除原文件、缓存、标注和学习记录。
4. 内容源可替换：阅读功能不能与 GitHub 仓库路径或某个内容提供方强绑定。
5. 合规先于上线：内容授权未确认时，只发布本地 EPUB 导入，不发布第三方刊物目录和下载入口。
6. 渐进增强：MVP 先支持 EPUB；PDF、MOBI、AI 翻译和音频同步不阻塞核心闭环。

## 4. 产品目标与非目标

### 4.1 MVP 目标

- 用户可以从设备选择并导入合法持有的 EPUB。
- 用户可以查看书库、目录并连续阅读。
- 应用可以可靠恢复上次阅读位置。
- 用户点击英文单词可以查看释义、音标和 TTS 发音。
- 用户可以将单词及原句加入“阅读生词”词包。
- 阅读生词能够进入现有学习计划和 SM-2 复习流程。
- 同一词多次遇到时不重复建卡，而是累积语境和遇见次数。
- 用户可以删除书籍并明确选择是否保留由该书产生的生词。

### 4.2 后续目标

- 经授权的在线刊物目录与按需下载。
- 句子翻译、段落翻译和语法分析。
- 阅读目标、阅读时长、连续阅读天数和生词率统计。
- 考研重点词高亮。
- 音频播放及正文同步。
- 多设备同步。

### 4.3 非目标

- MVP 不支持 PDF 重排阅读。
- MVP 不支持 MOBI。
- MVP 不提供 DRM 内容破解或导入。
- MVP 不提供应用内购买刊物。
- MVP 不自动上传用户导入的书籍或正文。
- MVP 不承诺完整实现 EPUB 3 的脚本、固定版式和交互媒体能力。

## 5. 用户与使用场景

### 5.1 主要用户

- 备考用户：希望在外刊中识别、积累和复习考研高频词。
- 中高级英语学习者：能够阅读英文原文，但查词打断明显。
- 已拥有 EPUB 的用户：希望在手机内离线阅读并沉淀生词。

### 5.2 核心用户故事

- 作为学习者，我希望导入 EPUB 并快速开始阅读。
- 作为学习者，我希望退出应用后仍回到上次读到的位置。
- 作为学习者，我希望点击陌生词立即看到释义，而不用切换应用。
- 作为学习者，我希望把生词连同原句加入复习，而不是手工复制。
- 作为学习者，我希望同一个词再次出现时看到自己遇到过几次。
- 作为学习者，我希望在单词详情中回到它出现的文章位置。
- 作为存储空间有限的用户，我希望知道每本书占用多少空间并能安全删除。

## 6. 信息架构与导航

底部主导航建议调整为：

```text
今日 | 阅读 | 计划 | 收藏 | 我的
```

如果必须维持四个入口，则将“收藏”移入“我的”：

```text
今日 | 阅读 | 计划 | 我的
```

阅读模块内部结构：

```text
阅读首页/书库
├── 继续阅读
├── 本地书籍
├── 导入 EPUB
├── 在线书库（授权后启用）
└── 阅读统计（后续）
    └── 书籍详情
        ├── 开始/继续阅读
        ├── 目录
        ├── 文件与来源信息
        └── 删除
            └── 阅读器
                ├── 目录/章节跳转
                ├── 阅读设置
                ├── 点击查词
                └── 书签/标注（增量版本）
```

## 7. 核心流程

### 7.1 导入 EPUB

1. 用户在“阅读”页点击“导入 EPUB”。
2. 系统打开文件选择器，仅显示 `.epub` 或对应 MIME 类型。
3. 系统复制文件到应用私有目录，解析元数据、封面、目录和章节。
4. 系统校验文件结构和可读内容。
5. 导入成功后进入书籍详情；重复文件提示“已经导入”。
6. 解析失败时删除临时文件并展示可理解的原因。

### 7.2 阅读与进度恢复

1. 用户打开书籍，默认进入上次阅读位置；首次打开进入正文首章。
2. 阅读器按章节加载正文，支持滚动阅读。
3. 用户停止滚动或离开页面时保存章节与文本定位信息。
4. 下次打开时恢复到相同段落附近。
5. 字号或屏幕尺寸变化不应导致进度完全失效。

### 7.3 点击查词并加入复习

1. 用户点击正文中的英文单词。
2. 阅读器选中标准词边界，并取得所在句子和定位信息。
3. 底部弹层显示原词、规范词、音标、释义、发音和加入按钮。
4. 用户点击“加入生词”。
5. 若词不存在，创建阅读生词卡和一条来源语境。
6. 若词已存在，只增加新的语境和遇见次数，并提示“已补充语境”。
7. 用户可以继续阅读，弹层操作不改变阅读进度。

### 7.4 从单词详情返回原文

1. 阅读生词详情展示来源书籍、章节和原句。
2. 用户点击来源，若书籍仍存在则打开对应位置。
3. 若原书已删除，仍显示保存的原句，但提示原文文件不可用。

### 7.5 删除书籍

1. 用户在书籍详情选择删除。
2. 系统展示文件占用空间及关联生词数量。
3. 用户选择：
   - 删除书籍，保留生词和已保存原句；
   - 删除书籍，并移除仅来源于该书且尚无学习记录的生词。
4. 有复习记录的词不得被静默删除。

优先级定义：P0 为 MVP 必须；P1 为 MVP 后首个增量；P2 为远期。

## 9. 阅读生词业务规则

### 9.1 词条标识

- MVP 使用规范化词形作为去重键：Unicode 规范化、转小写、统一弯直撇号、移除外围标点。
- 保留用户实际点击的 `surfaceForm`。
- 已存在于当前词库的词优先合并；不能因合并丢失既有复习状态。
- 后续引入词形还原时必须提供数据迁移，不能直接改变已有词条 ID。

### 9.2 语境规则

- 每条语境至少保存：书籍 ID、章节 ID、定位符、原句、添加时间。
- 相同书籍、章节、定位和规范词的记录视为重复。
- 每个词默认保留最近 20 条语境；超过上限时优先保留用户标记和用于卡片的语境。
- 删除书籍后保留已复制到语境记录中的原句，移除不可用的跳转能力。

### 9.3 计划规则

- 创建固定词包 `reading-vocabulary`，不为每本书创建独立学习计划。
- 新加入单词默认进入“未学习”状态，由现有计划分配到后续每日任务。
- 如果同词已经在其他词包学习，MVP 保持各词包进度隔离；后续版本再评估跨词包共享复习状态。

## 10. 阅读设置默认值

| 设置 | 默认值 | 范围/选项 |
|---|---:|---|
| 字号 | 18px | 14–30px |
| 行距 | 1.65 | 1.3–2.2 |
| 页边距 | 20px | 12/20/28px |
| 主题 | 跟随系统 | 亮色/深色/跟随系统 |
| 正文字体 | 系统衬线 | 衬线/无衬线 |

| 自动加入生词 | 关闭 | MVP 不允许无确认自动加入 |

## 11. 异常与空状态

- 空书库：解释支持的 EPUB 类型，并提供明确导入按钮。
- 文件过大：导入前显示大小；空间不足时不开始复制。
- 无有效正文：提示文件可能是固定版式、受 DRM 保护或已损坏。
- 解析中断：临时文件可清理，重新启动后不显示半成品书籍。
- 图片缺失：正文仍可阅读，显示占位而非崩溃。
- 字典不可用：显示原词和原句，仍允许稍后补充释义或加入生词。
- 原书已删除：来源卡显示原句和“原文件已删除”。
- 在线目录不可用：不影响本地书库和已下载书籍。

## 12. 数据与隐私

- 用户导入文件默认仅保存在应用私有目录。
- MVP 不上传 EPUB、章节正文、标注或查词历史。
- 若后续接入在线词典/翻译，发送前应明确说明发送范围，优先只发送用户选择的词或句子。
- 清空学习数据和删除书籍应分别处理，避免误删。
- 日志不得记录完整章节正文、用户文件路径中的敏感信息或第三方访问令牌。

## 13. 合规与内容发布门禁

远程刊物功能只有满足以下条件才能面向用户启用：

- 已确认内容的分发、缓存和应用内展示授权。
- 已确认上游仓库或目录数据的许可条件。
- 产品内展示必要的来源、权利说明和下架渠道。
- 内容目录通过服务端或构建时开关控制，可紧急关闭。
- 已定义侵权投诉、内容下架和已缓存文件处理流程。

在上述条件未完成前：

- 允许研发使用自有、公共领域或明确授权 EPUB 测试。
- 正式版本只提供用户本地导入。
- 不内置 `awesome-english-ebooks` 文件、直链、封面或完整目录。

## 14. 非功能要求

### 14.1 性能

- 100MB 以内 EPUB 导入过程中 UI 不应长时间无反馈。
- 普通章节打开至正文可交互目标小于 1 秒，冷启动目标小于 2 秒。
- 滚动过程中不因频繁写进度产生明显掉帧。
- 单次仅向 WebView 注入当前章节所需资源和数据。

### 14.2 稳定性

- 导入、解压和写数据库使用阶段状态或事务。
- 任一书籍解析失败不得影响其他书籍。
- 保存进度采取防抖，并在离开阅读器时强制刷新。
- 数据模型升级必须支持已有用户状态迁移。

### 14.3 兼容性

- iOS 和 Android 为 MVP 必须平台。
- Web 端允许暂缓本地 EPUB 导入，或使用浏览器文件能力实现受限版本。
- 支持 EPUB 2 与 EPUB 3 常见可重排文档。

## 15. 指标与埋点建议

MVP 可只在本地统计，若上传分析数据需单独完成隐私评审。

- 导入成功率、失败类型和耗时分位数。
- 阅读启动成功率、章节打开耗时。
- 每周阅读用户数、阅读时长和完成章节数。
- 每千词查词次数。
- 查词到加入生词转化率。
- 阅读生词次日/七日复习率。
- 从单词详情返回原文的使用率。

禁止采集完整书名、正文、原句或文件名作为通用分析事件属性。

## 16. MVP 验收场景

### AC-01 导入标准 EPUB

给定一个包含封面、NCX/nav 和多章节的合法 EPUB，当用户导入时，书库出现一本记录，目录顺序正确，正文和图片可显示。

### AC-02 防止重复导入

给定已经导入的同一文件，当用户再次导入时，不创建重复记录，并提供打开已有书籍的入口。

### AC-03 恢复进度

给定用户阅读至第三章中段，当应用被杀进程并重新打开时，进入该书应恢复到第三章相同段落附近。

### AC-04 点击查词

给定正文句子包含 `constraints`，当用户点击该词时，弹层显示选中词、所在原句、查词结果和 TTS 按钮。

### AC-05 创建阅读生词

当用户加入一个新词时，“阅读生词”词包增加一个条目，该条目包含原句和可返回的来源定位，并可被学习计划分配。

### AC-06 合并语境

给定同一规范词已经存在，当用户在另一篇文章再次加入时，词卡数量不增加，来源语境数量增加，原复习进度不变。

### AC-07 删除书籍

当用户删除书籍并选择保留生词时，EPUB 和解压缓存被移除，空间被释放，生词及保存的原句仍可查看，但返回原文按钮变为不可用。

### AC-08 异常文件

给定损坏或受 DRM 保护的 EPUB，导入失败时不留下可见的半成品记录，临时文件最终被清理，并展示明确错误。

### AC-09 离线阅读

给定书籍已导入，当设备无网络时，目录、正文、图片、进度、查词历史和加入生词功能仍可用；需要网络的词典结果允许降级。

## 17. 版本拆分与里程碑

### M0：基础工程，预计 2–3 个开发日

- 引入正式导航结构。
- 建立阅读模块目录和依赖边界。
- 接入 SQLite、文件系统和数据库迁移框架。
- 准备授权测试 EPUB fixture。

### M1：本地 EPUB 阅读，预计 5–8 个开发日

- 文件导入、校验、解析和书库。
- 书籍详情、目录、阅读器和进度恢复。
- 阅读设置、删除与异常恢复。

### M2：阅读生词闭环，预计 3–5 个开发日

- 点击选词、原句提取、释义与发音。
- 阅读生词词包、语境去重和现有计划集成。
- 从单词详情返回原文。

### M3：体验增强，预计 4–6 个开发日

- 书签、标注、搜索、性能优化和无障碍完善。
- 阅读统计和考研重点词高亮。

### M4：在线目录，预计 4–7 个开发日

- 仅在授权门禁通过后实施。
- Manifest 生成、远程目录、下载、校验、撤回和更新。

## 18. 上线标准

- 所有 P0 验收场景通过 iOS 和 Android 真机验证。
- 测试 EPUB 覆盖 EPUB 2、EPUB 3、嵌套路径、特殊字符路径、缺封面、损坏文件和大文件。
- 无已知会导致用户书籍、进度或复习状态丢失的 P0/P1 缺陷。
- 第三方内容入口符合第 13 节门禁；否则保持关闭。
- README、隐私说明和设置页说明支持的格式、存储方式与删除行为。
